## October 6, 2026 - The Revivial

After 4 years, I've returned to bring back what I left behind. Now, I know a majority of people reading this aren't familiar with the project, but I've decided that I'm going to bring it back!

I'm really not sure if I ever provided any files for the project, but I found all of the files laying in my google drive, source code and everything. And given the fact that I'm experienced in decomp now, why not bring this back and continue where I left off?

For context, this was mainly just a redo of the original game but with the ability to play as Luigi. There were icons, voice clips, the models and all. But there weren't any other major changes, which made it really unfinished. But anyways, I plan to revive this project and cook up some brand new ideas and/or levels for the newest release! I hope you all enjoy what I'll be cooking up!
